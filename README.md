# Hi, I'm Sean Johnson

I build apps and AI-agent tools by directing coding agents (Claude Code and Codex) rather than writing the code myself. I work with Vercel, Supabase, plugins and MCPs.

Before software I spent 15 years running operations: a dairy farm team of 22, advising commercial dairy farmers, and a mobile bar business with a team of 12.

**PropKeep** is the landlord app I built for my own 12-unit rental portfolio. It's live on the web and Google Play.

### Open-source tools here
- **review-layers**: layered code review for code an agent wrote, as a Claude Code plugin.
- **tenant-leak-check**: tests whether one customer can see another customer's data in a Supabase app.
- **baseline**: for each failing test, shows whether a change broke it or it was already broken.
- **push-guard**: a Claude Code plugin that blocks `git push` while tests fail.

Based in South Africa and open to remote work.
